# Design history

The current look (sunset gradient, ST monogram, marquees, particle
network, pill hover-reveal buttons) replaced an earlier flat
single-accent dark theme with a plain ticket-outline logo. The
redesign borrowed interaction patterns (marquee + fade-mask, hover
pill CTA, pill tab switcher, giant viewport-scale section breaks)
from a reference site the user pointed to, adapted to this project's
own content, gradient, and copy — see `docs/BRAND.md` for the current
identity.
