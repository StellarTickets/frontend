# Glossary

- **build/confirm pair** — the two backend endpoints (e.g.
  `POST /tickets/issue` then `POST /tickets/confirm-issue`) behind
  every on-chain write; see `src/lib/onchain.ts`.
- **PillButton** — the gradient hover-reveal CTA component used for
  primary actions across the marketing pages.
- **Marquee** — the seamless infinite-scroll pill row component (used
  for industries and the tech stack on the homepage).
- **ParticleNetwork** — the animated canvas background behind the hero.
