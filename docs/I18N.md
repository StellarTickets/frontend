# Internationalization

The app uses `next-intl` for i18n scaffolding. Currently, only English
is supported with messages defined in `messages/en.json`.

## Configuration

- `src/i18n.ts` - next-intl request configuration
- `messages/en.json` - English message catalogue

## Future expansion

Additional languages can be added by:

1. Creating new message files (e.g., `messages/es.json`)
2. Implementing locale detection logic in `src/i18n.ts`
3. Adding locale routing if needed
