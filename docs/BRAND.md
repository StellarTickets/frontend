# Brand

- **Name**: StellarTickets
- **Mark**: an "ST" monogram badge in the brand gradient (see
  `src/components/logo.tsx`)
- **Gradient**: violet `#a78bfa` -> magenta `#f472b6` -> amber
  `#f5b400`, 135deg — defined once as `BRAND_GRADIENT` in
  `logo.tsx` and mirrored as `--gradient-sunset` in `globals.css`
- **Type**: Space Grotesk (headings) + Inter (body)
- **Tone**: direct, technical, no unexplained crypto jargon — copy
  favors concrete claims ("the contract rejects any listing above the
  cap") over vague ones ("secure and trustless")
